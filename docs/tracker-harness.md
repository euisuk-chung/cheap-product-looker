# Tracker 검색 하네스

프로모션과 판매 옵션 변경으로 상품 URL이 자주 바뀌는 상황에 대응하기 위한 제품별 검색 계약이다.

## 제품별 설정

`products.json`의 각 `tracker`는 다음 값을 가진다.

- `searchQueries`: 판매처에서 매 실행 사용할 검색어
- `requiredTerms`: 동일 제품 판단에 반드시 필요한 단어
- `excludedTerms`: 다른 라인·제형을 걸러낼 단어
- `packagePolicy`: `same_product_any_quantity`; 같은 제품이면 수량·구성 차이를 허용하고 총용량으로 정규화
- `discoveryPolicy`: `every_run`; 승인 URL이 정상이어도 새로운 기획 URL을 탐색

## 실행 절차

1. 판매처별 서브에이전트가 승인 URL의 현재 옵션, 총용량, 가격, 배송비와 재고를 확인한다.
2. 같은 실행에서 `searchQueries`를 모두 사용해 현재 판매 중인 공식 페이지를 검색하고, 검색 결과의 첫 항목만 고르지 않고 접근 가능한 동일 제품 후보를 모두 조사한다.
3. 필수어·제외어와 제품 제형을 확인해 다른 라인을 제거한다.
4. 판매 구성에 포함된 같은 제품의 총용량을 `g` 또는 `ml`로 합산한다. 밀도 정보 없이 `ml`와 `g`를 서로 변환하지 않는다.
5. 상품가와 필수 배송비가 모두 확인되고 재고가 있는 후보끼리 `일반 구매 총액 ÷ 총용량`을 계산해 판매처별 오름차순으로 순위를 매긴다.
6. 승인 URL과 다른 유효 페이지는 `promotion` 또는 `replacement` 후보로 저장한다.
7. 리뷰 에이전트가 후보의 동일 제품 여부와 가격 근거를 다시 확인한다.
8. 리뷰를 통과한 비교 가능 후보 중 판매처별 최저 단가 URL을 코디네이터가 자동 매핑하고 이력에 기록한다.

가격 비교는 일반 구매 총액을 판매 구성 총용량으로 나눈 `원/g` 또는 `원/ml`을 기준으로 한다. 배송비를 확정할 수 없는 후보는 단위 가격 최저가 판정에서 제외한다.

추적 현황 화면은 같은 판매처의 복수 후보를 단위가 순으로 보여 주고 조사·리뷰 상태와 `현재 추적 URL`을 구분한다. 공개 가격 보드는 리뷰를 통과해 기록된 36시간 이내 관측값을 우선하며, 새 관측이 없으면 마지막으로 확인된 구매 링크를 오래된 상태로 유지한다.
